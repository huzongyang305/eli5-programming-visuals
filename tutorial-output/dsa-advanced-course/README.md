## 学习建议

- **循序渐进**：按顺序学习，后面的章节依赖前面的知识
- **动手实践**：不要只看代码，亲自运行并修改示例
- **可视化辅助**：遇到抽象概念时，查看 ELI5 图解获取直观理解
- **双语言对比**：每个算法都用 C++ 和 Java 实现，理解不同语言的思维方式

## 前置要求

- 掌握数组、链表、栈、队列等基础数据结构
- 了解基本排序算法（冒泡、快速、归并）
- 熟悉递归和分治思想
- 具备 C++ 或 Java 编程基础
