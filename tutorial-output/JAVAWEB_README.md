# JavaWeb开发完整教程

> 从零开始学习JavaWeb开发，通过通俗易懂的语言、生活类比和交互式可视化图解。

## 🎯 课程概览

本教程包含**10个核心章节**，预计学习时间**30小时**，适合有Java基础但无Web开发经验的学习者。

### 学习路径

```
HTTP协议 → Servlet → JSP → EL表达式 → JSTL
    ↓
Session/Cookie → 过滤器 → 监听器
    ↓
JDBC数据库 → MVC设计模式
```

## 💡 学习建议

1. **按顺序学习** - 每个章节都依赖前置知识
2. **动手实践** - 完成每章的练习题，搭建Tomcat环境
3. **使用可视化工具** - 抽象概念配合图解更容易理解
4. **项目实战** - 第10章提供完整的MVC项目示例

## 🛠️ 技术栈

- **后端**: Java EE (Servlet, JSP, JDBC)
- **服务器**: Apache Tomcat 9+
- **数据库**: MySQL 8+
- **构建工具**: Maven
- **IDE**: IntelliJ IDEA / Eclipse
