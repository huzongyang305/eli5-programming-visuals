# 第二章：命题逻辑

## 简介

你是否经常听到这样的话："如果明天下雨，我就不去公园"或者"只有完成作业才能玩游戏"？这些句子背后隐藏着一种逻辑结构，这就是我们要学习的**命题逻辑**。

命题逻辑研究的是简单陈述句之间的逻辑关系。它帮助我们判断一个结论是否可以从某些前提中正确推导出来。想象一下，你正在玩一个推理游戏，需要根据已知线索推断出真相——命题逻辑就是你的推理工具箱！

---

## 核心概念定义

### 什么是命题？

**命题（Proposition）**是一个可以判断真假的陈述句。每个命题要么为**真（True）**，要么为**假（False）**，不能同时既真又假。

例如：
- ✅ "北京是中国的首都" —— 是命题（真）
- ✅ "2 + 2 = 5" —— 是命题（假）
- ❌ "你好吗？" —— 不是命题（疑问句）
- ❌ "请关门" —— 不是命题（祈使句）
- ❌ "x > 5" —— 不是命题（含有变量，真假不确定）

### 逻辑联结词

我们用符号来表示命题之间的逻辑关系：

| 符号 | 名称 | 含义 | 示例 |
|------|------|------|------|
| ¬ | 否定（非） | 取反 | ¬P：P的否定 |
| ∧ | 合取（与） | 两者都为真 | P ∧ Q：P且Q |
| ∨ | 析取（或） | 至少一个为真 | P ∨ Q：P或Q |
| → | 蕴含（如果...那么...） | 条件关系 | P → Q：如果P则Q |
| ↔ | 等价（当且仅当） | 双向条件 | P ↔ Q：P当且仅当Q |

### 真值表

真值表列出了所有可能的真假组合及其结果。以 P ∧ Q 为例：

| P | Q | P ∧ Q |
|---|---|-------|
| T | T |   T   |
| T | F |   F   |
| F | T |   F   |
| F | F |   F   |

T = True（真），F = False（假）

### 重要概念

1. **重言式（Tautology）**：无论变量取何值，结果永远为真的命题公式
   - 例如：P ∨ ¬P（排中律）

2. **矛盾式（Contradiction）**：无论变量取何值，结果永远为假的命题公式
   - 例如：P ∧ ¬P

3. **可满足式（Satisfiable）**：至少存在一种赋值使其为真的命题公式

## 生活类比

### 类比1：电路开关

想象两个开关控制一盏灯：

- **串联电路（AND）**：两个开关都必须打开，灯才会亮
  - 对应：P ∧ Q
  
- **并联电路（OR）**：只要有一个开关打开，灯就会亮
  - 对应：P ∨ Q

- **反向开关（NOT）**：按下开关反而关灯
  - 对应：¬P

### 类比2：餐厅点餐

你去餐厅点餐：

- "我要汉堡 **并且** 可乐" → P ∧ Q（必须都有）
- "我要咖啡 **或者** 茶" → P ∨ Q（选一个或都要都可以）
- "**如果**有优惠券，**那么**我可以打折" → P → Q
- "**只有**会员 **才**能享受折扣" → Q → P（注意方向！）
- "我**当且仅当**有钱时才消费" → P ↔ Q（充分必要条件）

### 类比3：考试规则

学校的考试规则：

- "及格的条件是：平时成绩合格 **且** 期末考试成绩合格"
  - 对应：P ∧ Q → 及格
  
- "缺考 **或** 作弊都会导致不及格"
  - 对应：P ∨ Q → 不及格

- "**如果**你努力学习，**那么**你会取得好成绩"
  - 对应：P → Q
  - 注意：这不代表"如果你没努力学习，就一定不会取得好成绩"

## 代码示例

```python
# Python实现命题逻辑运算

def AND(p, q):
    """逻辑与"""
    return p and q

def OR(p, q):
    """逻辑或"""
    return p or q

def NOT(p):
    """逻辑非"""
    return not p

def IMPLIES(p, q):
    """蕴含：如果p则q
    等价于：非p 或 q
    只有当p为真且q为假时，结果才为假
    """
    return (not p) or q

def IFF(p, q):
    """等价：p当且仅当q"""
    return p == q

# 生成真值表
def print_truth_table():
    print("P | Q | P∧Q | P∨Q | P→Q | P↔Q")
    print("-" * 40)
    
    for p in [True, False]:
        for q in [True, False]:
            and_val = AND(p, q)
            or_val = OR(p, q)
            implies_val = IMPLIES(p, q)
            iff_val = IFF(p, q)
            
            # 用T/F表示
            p_str = "T" if p else "F"
            q_str = "T" if q else "F"
            and_str = "T" if and_val else "F"
            or_str = "T" if or_val else "F"
            implies_str = "T" if implies_val else "F"
            iff_str = "T" if iff_val else "F"
            
            print(f"{p_str} | {q_str} |  {and_str}  |  {or_str}  |  {implies_str}  |  {iff_str}")

print("=== 真值表 ===")
print_truth_table()

# 验证德摩根定律
print("\n=== 验证德摩根定律 ===")
print("¬(P ∧ Q) ≡ ¬P ∨ ¬Q")
print("¬(P ∨ Q) ≡ ¬P ∧ ¬Q")
print("-" * 40)

for p in [True, False]:
    for q in [True, False]:
        left1 = NOT(AND(p, q))
        right1 = OR(NOT(p), NOT(q))
        
        left2 = NOT(OR(p, q))
        right2 = AND(NOT(p), NOT(q))
        
        match1 = "✓" if left1 == right1 else "✗"
        match2 = "✓" if left2 == right2 else "✗"
        
        print(f"P={p}, Q={q}: {match1} {match2}")

# 实际应用：权限检查系统
print("\n=== 实际应用：权限检查 ===")

def check_permission(is_admin, has_token, is_owner):
    """
    检查用户是否有删除文件的权限
    规则：管理员 或 (有令牌 且 是文件所有者)
    """
    can_delete = is_admin OR (has_token AND is_owner)
    return can_delete

# 测试不同情况
test_cases = [
    (True, False, False),   # 管理员，无令牌，非所有者
    (False, True, True),    # 非管理员，有令牌，是所有者
    (False, True, False),   # 非管理员，有令牌，非所有者
    (False, False, True),   # 非管理员，无令牌，是所有者
]

for admin, token, owner in test_cases:
    result = check_permission(admin, token, owner)
    print(f"管理员:{admin}, 有令牌:{token}, 是所有者:{owner} → 可删除:{result}")

# 验证重言式
print("\n=== 验证重言式：P ∨ ¬P（排中律）===")
for p in [True, False]:
    result = OR(p, NOT(p))
    print(f"P={p}: P ∨ ¬P = {result}")
```

输出结果：
```
=== 真值表 ===
P | Q | P∧Q | P∨Q | P→Q | P↔Q
----------------------------------------
T | T |  T  |  T  |  T  |  T
T | F |  F  |  T  |  F  |  F
F | T |  F  |  T  |  T  |  F
F | F |  F  |  F  |  T  |  T

=== 验证德摩根定律 ===
¬(P ∧ Q) ≡ ¬P ∨ ¬Q
¬(P ∨ Q) ≡ ¬P ∧ ¬Q
----------------------------------------
P=True, Q=True: ✓ ✓
P=True, Q=False: ✓ ✓
P=False, Q=True: ✓ ✓
P=False, Q=False: ✓ ✓

=== 实际应用：权限检查 ===
管理员:True, 有令牌:False, 是所有者:False → 可删除:True
管理员:False, 有令牌:True, 是所有者:True → 可删除:True
管理员:False, 有令牌:True, 是所有者:False → 可删除:False
管理员:False, 有令牌:False, 是所有者:True → 可删除:False

=== 验证重言式：P ∨ ¬P（排中律）===
P=True: P ∨ ¬P = True
P=False: P ∨ ¬P = True
```

## 常见误区

### 误区1：混淆"或"的含义
- **日常语言的"或"**：通常是"异或"（XOR），即二选一
  - "你要喝茶还是咖啡？"（通常指选一个）
  
- **逻辑中的"或"（∨）**：是"包含性或"，可以同时为真
  - P ∨ Q 在 P和Q都为真时也是真
  
- **记忆技巧**：逻辑中的∨更像"至少一个"

### 误区2：误解蕴含关系
- **错误理解**：认为 P → Q 意味着 P 是 Q 的原因
- **正确理解**：P → Q 只表示"如果P为真，那么Q必须为真"
- **关键点**：当P为假时，P → Q 总是为真（无论Q是什么）
  - 例子："如果猪会飞，那么我会成为总统" —— 因为猪不会飞（P为假），所以这个命题为真！

### 误区3：混淆充分条件和必要条件
- **P → Q**：P是Q的**充分条件**，Q是P的**必要条件**
- **例子**："如果是狗，那么是动物"
  - "是狗"是"是动物"的充分条件
  - "是动物"是"是狗"的必要条件
  - 但"是动物"不是"是狗"的充分条件（猫也是动物）

### 误区4：逆否命题的混淆
- **原命题**：P → Q
- **逆命题**：Q → P（不一定等价！）
- **否命题**：¬P → ¬Q（不一定等价！）
- **逆否命题**：¬Q → ¬P（与原命题等价！）

**记忆口诀**：逆否命题保真假，逆命题和否命题不保证

### 误区5：忽略括号的重要性
- **错误**：P ∧ Q ∨ R 不明确
- **正确**：(P ∧ Q) ∨ R 或 P ∧ (Q ∨ R)
- **原因**：不同的括号位置会导致完全不同的结果
