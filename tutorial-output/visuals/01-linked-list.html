🚂 链表就像火车车厢

每节车厢都知道下一节车厢在哪里

💡 生活类比

想象一列火车：

  • 每节车厢 = 链表中的一个节点（Node）
  • 车厢里的货物 = 节点存储的数据（Data）
  • 车厢之间的挂钩 = 指向下一个节点的指针（Next）
  • 最后一节车厢 = 指向null，表示结束

关键特点：要找到第5节车厢，必须从第1节开始一节节往后数！不能直接跳过去。

⚡ 性能对比：数组 vs 链表

操作 数组（Array） 链表（Linked List） winner
访问第n个元素 ⭐ O(1) - 直接跳转 🐢 O(n) - 从头遍历 ✅ 数组胜
在开头插入 🐢 O(n) - 需要移动所有元素 ⭐ O(1) - 只需改指针 ✅ 链表胜
在中间插入 🐢 O(n) - 需要移动后续元素 ⭐ O(1) - 已知位置时很快 ✅ 链表胜
内存使用 ⭐ 紧凑，只存数据 📦 额外需要存储指针 ✅ 数组胜
大小固定吗？ ❌ 创建后难以扩容 ✅ 动态增长，无上限 ✅ 链表胜

💻 代码实现

C++ 版本

struct Node { int data; // 货物（数据） Node* next; // 挂钩（指向下一节车厢） Node(int val) : data(val), next(nullptr) {} }; // 在头部添加节点 - O(1) void pushFront(Node*& head, int val) { Node* newNode = new Node(val); // 制造新车厢 newNode->next = head; // 新车厢挂钩连到旧车头 head = newNode; // 更新车头 }

Java 版本

class Node { int data; // 货物（数据） Node next; // 挂钩（指向下一节车厢） Node(int val) { this.data = val; this.next = null; } } // 在头部添加节点 - O(1) void pushFront(Node head, int val) { Node newNode = new Node(val); // 制造新车厢 newNode.next = head; // 新车厢挂钩连到旧车头 head = newNode; // 更新车头 }

🎯 核心要点总结

  • 链表的本质：每个节点存储数据和下一个节点的地址
  • 优点：插入删除快（O(1)），动态大小，内存灵活
  • 缺点：随机访问慢（O(n)），额外内存开销，缓存不友好
  • 适用场景：频繁插入删除、不确定数据量、实现栈/队列
  • 不适用场景：需要频繁随机访问、数据量固定且小
