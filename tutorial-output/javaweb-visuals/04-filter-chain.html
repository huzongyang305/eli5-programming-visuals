🛡️ 过滤器链(Filter Chain)可视化

💡 生活类比：机场安检流程

乘客 = HTTP请求 - 想要到达目的地（Servlet）

安检口 = Filter - 每个检查一道关卡（编码、登录、日志）

登机口 = Servlet - 最终处理请求的地方

所有安检口串联 = FilterChain - 必须依次通过

📖 过滤器链工作原理

1. 请求到达时，按配置顺序依次经过每个Filter

2. 每个Filter可以修改请求或响应

3. Filter调用chain.doFilter()将请求传递给下一个Filter

4. 所有Filter通过后，请求才到达Servlet

5. 响应返回时，按相反顺序再次经过Filter链

// 编码过滤器示例
@WebFilter("/*")
public class EncodingFilter implements Filter {
    public void doFilter(ServletRequest request, 
                        ServletResponse response, 
                        FilterChain chain) 
                        throws IOException, ServletException {
        // 1. 请求前处理
        request.setCharacterEncoding("UTF-8");
        response.setContentType("text/html;charset=UTF-8");
        
        // 2. 传递给下一个过滤器或Servlet
        chain.doFilter(request, response);
        
        // 3. 响应后处理（可选）
        System.out.println("请求处理完成");
    }
}
