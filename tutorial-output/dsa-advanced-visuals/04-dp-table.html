Real-World Analogy: Climbing Stairs
Imagine you're climbing a staircase where you can take either 1 or 2 steps at a time. How many different ways can you reach the top? Instead of recalculating from scratch each time, DP remembers previous results—like leaving breadcrumbs on each step you've already climbed! 🍞✨

🔝 Top-Down (Memoization)
Start from the problem and break it down. Store results as you go back up.
def climb(n, memo={}): if n in memo: return memo[n] if n <= 2: return n memo[n] = climb(n-1) + climb(n-2) return memo[n]
🔽 Bottom-Up (Tabulation)
Start from base cases and build up to the solution. Fill the table iteratively.
def climb(n): dp = [0] * (n+1) dp[1] = 1 dp[2] = 2 for i in range(3, n+1): dp[i] = dp[i-1] + dp[i-2] return dp[n]
